# Мини-презентация

`gerasimov-presentation.pdf` — согласованный пользователем вариант для публичной страницы, с открытыми контактами и ссылками на резюме. Файл становится общедоступным после публикации: удаление или замена не отзывают уже скачанные копии. При обновлении файла проверяйте содержание, ссылки и расположение на страницах; исходного редактируемого файла здесь нет.

Кнопка на главной отправляет фиксированное событие `presentation_download` в Яндекс Метрику (счётчик 108401876) и GA4 (G-DM41FJYWX0). В Метрике для отчёта по цели в интерфейсе счётчика нужно создать цель типа «JavaScript-событие» с идентификатором `presentation_download`; доступ к кабинету из репозитория не подтверждён. В GA4 событие можно найти в отчёте по событиям после обработки; при необходимости пометить его ключевым в интерфейсе. GA4 может также автоматически собирать `file_download` при включённой улучшенной статистике — не суммируйте эти события как независимые скачивания.

Событие означает нажатие на кнопку, не успешное сохранение PDF: блокировщики, ошибки сети, переходы напрямую по адресу PDF и отключённый JavaScript не учитываются; повторные нажатия учитываются отдельно. Счётчики загружаются существующим кодом страницы; данный обработчик не является механизмом согласия и не передаёт адреса, контакты или ввод пользователя как параметры события. Фактическое получение событий в кабинетах нужно проверить после публикации.

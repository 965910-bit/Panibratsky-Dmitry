# Повторный аудит портфолио — 16 ноября 2026

## Границы и метод

Проверены текущая ветка, HTML и локальные ресурсы, конфигурация индексации, код AI, тесты, GitHub Actions, извлекаемый текст PDF и отдельные публичные страницы scm-news.ru. Данные резюме использованы для сопоставления, но независимо не подтверждены. Это не исчерпывающая экспертиза всех приложений, юридический аудит или пентест. Браузерная проверка, Lighthouse, кабинеты аналитики и права Firebase недоступны. На момент составления аудит не изменял сайт и не гарантирует отсутствие иных проблем; последующие локальные изменения по просьбе владельца описаны в README.

## Критично: достоверность и документы

**Уточнение владельца:** прежняя и текущая фамилии принадлежат одному человеку. Ранее вывод о принадлежности документов другому человеку был ошибочным.

1. **На публичной странице сертификатов была ссылка на диплом, выданный на прежнюю фамилию владельца.** `/certificates.html` представляет его как подтверждение квалификации Дмитрия Герасимова; опубликованный `files/diplom-commercial-director.pdf` при чтении содержит другую фамилию. Страница с другими документами того же раздела тоже требует сверки. Это мой пропуск в предыдущих изменениях. Рекомендация: не переименовывать или редактировать документы, временно исключить неподтверждённые документы и утверждения из публичного портфолио, проверить все оригиналы и получить согласие владельца. Доступность старых URL и копии в истории/кэшах проверить отдельно.
2. **Четыре старых PDF в `files/` содержат прежнюю фамилию владельца:** файлы с префиксами `cltd-`, `cpl-`, `cscp-`, `ctsc-`. PDF CLTD фактически доступен на сайте. Соседняя HTML-версия показывала Герасимова, хотя соответствующий PDF указывает прежнюю фамилию; HTML-копию нельзя считать подлинным доказательством. Не делаю вывод о подлинности документов или полном списке затронутых файлов. У некоторых старых файлов извлекаемого текста нет, необходима визуальная проверка. Некоторые сроки действия могли истечь — проверять по каждому оригиналу.
3. **`files/lead-magnet.pdf` тоже содержит прежнюю фамилию**; документ присутствовал в исходной версии на момент аудита. Нужна проверка всех публичных PDF, изображений и HTML-версий на принадлежность, личные данные и права публикации. Извлечение текста не обнаруживает надписи на изображениях.
4. Удалённый из текущего дерева старый PDF резюме по проверенному публичному адресу показывает страницу GitHub Pages «404». Это не подтверждает удаление копий из истории Git, зеркал, поисковых кэшей и сторонних архивов. Репозиторий публичный: предыдущие версии и файлы доступны через GitHub независимо от ссылок на сайте. Проверить сохранённые копии, принять меры по правилам GitHub и при необходимости запросить удаление из поискового кэша; переписывание истории согласовать отдельно.

## Высокий приоритет: содержание и доверие

5. **`projects.html` доступна с главной и содержит многочисленные неподтверждённые утверждения.** Например, заявлены диссертация с защитой в 2027 году, книга, показатели Telegram, внедрение AI для прогнозирования спроса в Леруа Мерлен и TOP-2 по CSat. В предоставленном резюме TOP-2 относится к продуктивности, а CSat — TOP-10; смешивать их нельзя. ЮЛСАН на странице указан за 2013–2014, тогда как в предоставленном резюме объединённый период Авто-Притяжение / ЮЛСАН — октябрь 2014 — май 2021. Отсутствие факта в резюме не доказывает его ложность, но публиковать как подтверждённый без согласования нельзя. Рекомендация: сверить каждую карточку с оригиналами и владельцем, временно скрыть неподтверждённые заявления, чётко отделить планы от выполненных проектов.
6. На `experience.html` часть утверждений подтверждается резюме, но попадание каждой метрики в правильный период и организацию следует сверить построчно; важно не превращать собственные данные кандидата в независимую проверку. По годам есть промежутки и совместительства: «15+ лет» нужно трактовать как опыт с 2011 года, а не автоматически как 15 полных непрерывных лет руководства. Проверить точную дату начала и суммарный стаж перед использованием строгой цифры.
7. `certificates.html` заявляет количество дипломов, квалификации и номера. Проверить их принадлежность, актуальность, право публикации номеров и доказательства отдельно; одинаковый номер показан на двух разных карточках. Скрытие части номера CSS не делает его секретным: полное значение остаётся в HTML.
8. Главная предлагает AI-ассистента, но фактическое подключение backend и провайдера не подтверждено. GitHub Pages сам Node не запускает; локальный сервер без ключа отвечает сообщением о недоступности. При недоступном API пользователь увидит ошибку только после отправки. До запуска лучше явно показывать статус или предлагать прямой контакт; проверить фактический запрос в браузере после конфигурации.

## Безопасность и приватность

9. Публичные `admin.html`, `cabinet.html`, `promotion.html`, `login.html` и части `scm-platform/` не становятся закрытыми благодаря `noindex`. У `login.html` Firebase-конфигурация видна в браузере — это обычная модель Firebase, сама по себе не доказательство утечки секрета; решающими являются правила базы, авторизация и ограничения API. Без доступа к Firebase и Apps Script их проверить нельзя. Не вводить чувствительные данные до проверки; ранее опубликованный пароль сменить, отозвать сессии и проверить журналы.
10. Данные `localStorage` на устройствах посетителей не являются защищённым серверным хранилищем; эти данные доступны скриптам соответствующего origin и не синхронизируются автоматически между устройствами. Некоторые legacy-интерфейсы формируют HTML из данных: требуется отдельная проверка источников и экранирования, а не утверждение об установленной уязвимости.
11. Счётчики на главной запускаются без реализованного механизма согласия; в `trends.html` локально указан `webvisor:true`. Проверить применимые требования к уведомлению, согласию и политике обработки, настройки обеих аналитических систем и исключение содержимого AI-чата, полей форм и личных данных. Реквизиты и доступ к кабинетам не проверены.
12. Встроенные лимиты AI привязаны к процессу и socket IP: за reverse proxy несколько посетителей могут разделять квоту, а при нескольких экземплярах или перезапуске лимиты не общие. Проверка Origin не заменяет аутентификацию/WAF, запросы без Origin также допускаются. До запуска нужны сетевые лимиты, расходы/квоты, мониторинг, согласование внешнего провайдера и политики данных. Модель может ошибаться и подвергаться prompt injection. Тесты используют заглушку, не реального провайдера.
13. Статический локальный Node-сервер в `server/assistant.js` предназначен для превью, не считать его полноценной production-защитой. Для GitHub Pages его правила фильтрации путей вообще не применяются.

## SEO, навигация и доступность

14. Текущая опубликованная карта содержит 15 собственных URL; главная, опыт и новый материал о ДНК открываются с обновлённым содержимым. Для адреса старого PDF получена страница 404. Из этого не следует, что Google уже обработал обновлённую sitemap или индексирует нужные страницы. Проверить статус обработки, причины исключения и выбранный Google canonical в Search Console, аналогично проверить Яндекс.
15. Автоматический статический разбор локальных ссылок не обнаружил отсутствующих файлов среди проверенных HTML-ссылок/ресурсов, но обнаружил якоря без соответствующего статического `id`: в `trends-logistics.html` (например, `#logistics`, `#2024`) и `scm-platform/inventory-methodology.html` (например, `processes.html#sop`, `calculators.html#forecast`). Некоторые могут использоваться JavaScript для фильтрации, поэтому до исправления требуется интерактивная проверка, а не автоматическое удаление. Существующие тесты не проверяют якоря.
16. У ряда legacy-страниц в исходном HTML по два `h1`: `calculators.html`, `certificates.html`, `projects.html`, `tools.html`, `wiki.html`. Не считать это само по себе причиной падения позиций: проверить структуру и видимость заголовков, сделать иерархию понятной для людей и ассистивных технологий.
17. `prompts.html` — около 4,6 МБ HTML в репозитории. Это повод измерить передачу, загрузку, работу на слабых устройствах и пользу страницы, но не доказательство плохих Core Web Vitals. Проверить список и актуальность промптов, продумать отложенную загрузку/разбиение без потери полезного контента.
18. На главной есть canonical, метаописание, Person JSON-LD, а картинки имеют размеры и alt. Это положительные признаки, но они не гарантируют поисковую видимость или расширенные результаты. Проверить браузером мобильное меню, переключение темы, навигацию с клавиатуры, контрастность, адаптивность, формы и реальную разметку при отключённом JS; замеры не проводились.
19. `manifest.json` по-прежнему описывает проект как сборщик новостей; проверить согласованность названия, иконок, стартового URL и цвета с новой ролью портфолио. `sw.js` использует network-first для главной и новостей, но офлайн-копия может устареть; проверить обновление старых версий service worker на реальных устройствах.

## Надёжность и автоматизация

20. Последний видимый запуск `Update News` на `main` от 16.11.2026 02:37 UTC завершился ошибкой на шаге `Commit and push if changed`: запуск GitHub Actions № 43793331375. Метаданные шага получены, подробный лог скачать не удалось; причина неизвестна, нельзя утверждать, что это конфликт, права или ошибка данных. Проверить лог в GitHub Actions, следующие запуски и фактическую свежесть новостей. Расписание workflow само по себе не подтверждает успешное выполнение.
21. Несколько workflow записывают данные в репозиторий. У обновления новостей и проверки ссылок есть общая concurrency-группа, но HH workflow не задаёт явных `contents: write`; в зависимости от настроек репозитория push может быть запрещён. `replace-surname.yml` имеет широкое действие `git add .`, запускается вручную и может внести нежелательные замены, в том числе в документы и данные: лучше удалить/ограничить его после согласования. Перепроверить права, конкурентные записи и обработку ошибок, не запускать workflow вслепую.
22. В `package.json` нет lock-файла, а Telegram workflow выполняет `npm install` с диапазонами версий. Сборка зависимостей может различаться со временем; проверить совместимость, добавить lock-файл и воспроизводимую установку с `npm ci` при отдельном изменении. Доступность внешних источников новостей и Telegram не проверена.
23. README содержит старые ссылки на структуру проекта, которую нужно сверить (`стиль.css`, `expertise.css`, корневой `wiki.json`). Описание исключения резюме говорит «в этой ветке», хотя PR уже слит. Обновить операционную документацию после проверки публикации и принять единый способ развёртывания.

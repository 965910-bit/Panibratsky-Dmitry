КАК ЧИТАТЬ ДАННЫЕ

Выборка — не весь рынок.

Источник — ответы API hh.ru по указанным поисковым запросам за последние 30 дней на момент сбора. Одинаковые вакансии внутри одной выборки объединяются по идентификатору. Выборки могут пересекаться: складывать их нельзя.

Зарплатный показатель — среднее нижних границ объявленных зарплат в рублях, только среди вакансий с указанным значением. Это не средняя выплата и не зарплата всех соискателей. Вакансии могут отличаться по графику, регионам и условиям. Доступная выдача API может быть ограничена; результаты не являются репрезентативным срезом всего рынка.

При сбое сбора сохраняется последняя версия. Дата и предупреждение об устаревании отображаются для каждой выборки. На текущем этапе нельзя гарантировать ежедневное обновление.

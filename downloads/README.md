# Помощник подключения Яндекс Вебмастера

`SCM-Yandex-Webmaster-connect.zip` содержит локальный помощник и инструкцию для Windows. Архив не содержит учётных данных. Подключение требует согласия владельца, Python и GitHub CLI с правом управления секретами репозитория. Код помощника находится в `scripts/webmaster_yandex_connect.py`; два соседних модуля нужны для его работы. В архив включена версия из main на момент подготовки; при изменении исходников архив следует пересобрать и сравнить с ними.

Реальный OAuth и работа в Windows не проверены. Помощник не включает workflow; постоянная очередь и автоматическое обновление токена не реализованы. Не передавайте пароли, токены и секреты в чате.

`SCM-Yandex-Webmaster-connect-v2.zip` — альтернативный помощник через официальный браузерный код подтверждения и PKCE: не запрашивает client secret, но также не проверен с реальным кабинетом. Исходник — `scripts/webmaster_yandex_code_connect.py`. Оба архива публичны и не содержат пользовательских ключей.

## Невыполненное и риски

- `sameAs`: добавить только подтверждённые личные профили; канал Telegram не подменяет автоматически личный профиль. Фиктивный SearchAction не добавлен: реального поиска `/?q=` нет. Для `trends.html` dateModified не указан без подтверждённой даты существенного обновления страницы; FAQPage сохранён без дублирования.
- Answer-first частично: см. `answer-first-todo.md`. Проекты, тренды, результаты, сертификаты и бизнес-план требуют проверки по документам; владельцу — подтвердить числа и актуальность. Нет данных для внешних ссылок, полевых CWV и цитирования.
- `checklist.html` и `promotion.html` имеют Disallow для wildcard: робот может не увидеть noindex, а AI-группы не наследуют запрет. Это не авторизация. См. `p0-report.md`.
- В Prompt Hub данные перенесены без изменения 3035 объектов, но HTML содержит только 30 строк: при отключённом JS полный каталог доступен как JSON, а не прежней таблицей. Проверить скорость, сетевые ошибки, мобильную работу и доступность модалки; внешние якоря `#prompt-N` открывают соответствующий объект при JS. Исторические якоря в исходной таблице не обнаружены.
- Размеры 10 локальных фото определены Pillow: 2688×3456. Не определён размер удалённого tracking pixel. Визуальное влияние фото, заголовков и breadcrumb проверить в браузере.
- `scripts/check_broken_links.py` работает по сетевым новостным адресам и может менять data/news.json. Безопасно запущен на отдельной копии: первоначально нет requests, после установки во временный каталог за 25 с не завершился из-за ограничения сети. Не подтверждает отсутствие битых ссылок; репозиторий с данными не менялся.
- `node --check` для каждого `js/*.js`: базовый `js/analytics.js` содержит HTML и не проходит синтаксис. Остальные проверенные файлы проходят; требуемые отдельные проверки прошли. Не считать это новой регрессией.
- Логи HH недоступны из-за внешнего хранилища, а не обязательно из-за ошибки авторизации GitHub; runtime/причину падения нельзя установить. Повторный запуск отложен: существующий workflow может коммитить любые `data/*.json`.
- После деплоя проверить 5 страниц, консоль, мобильные ширины, Prompt Hub, опубликованный sitemap и исключение `audit/` из Pages. Audit остаётся видимым в публичном репозитории. Ни один из результатов не доказывает ранжирование, rich results или AI-цитирование.

## Откат

Использовать `git revert <hash>` для соответствующих коммитов текущей ветки в обратном порядке зависимостей; например, Prompt Hub и его тесты/данные — `git revert 8951194` после учёта последующих изменений. Не выполнять `reset --hard` на общей ветке: он может уничтожить чужие изменения. До слияния можно закрыть PR или отменить коммиты на текущей ветке.

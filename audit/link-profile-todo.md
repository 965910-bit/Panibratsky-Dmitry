# Ссылочный профиль — ручная проверка

Требуется выгрузка referring domains, анкор-листа и потенциально токсичных ссылок; без неё P2 по ссылкам не выполним. Нужны источник, дата и правила оценки. Само по себе название «токсичная ссылка» из инструмента не доказывает вред или необходимость disavow. Внешних ссылочных данных в этой работе нет.
